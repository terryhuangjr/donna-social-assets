# donna-social-assets

Public media host for cards rendered by the DonnaT content pipeline.

The Instagram publishing API cannot take a file upload — it takes a **URL** and
fetches the image itself. This repo is where the rendered 4:5 feed cards and
9:16 story cuts live so Buffer can pull them.

Layout: `<YYYY-MM-DD>/<listing>-<job>[-story].jpg`

Only finished, publish-ready artwork belongs here. Nothing secret, no listing
documents, no credentials — this repo is public by design.
